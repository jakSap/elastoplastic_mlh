# Tensile-instability stretching test (pure fluid)

Demonstrates the SPH/meshless **tensile instability** on a pure fluid and how
the kernel choice affects it: cubic spline (prone) vs Wendland C2 (suppresses
pairing). Two runs, identical except for the kernel.

## Setup

- Domain: periodic box **[-10, 10] x [-1, 1]**, single material (matId 0).
- IC: uniform lattice, `delta_p = 0.05` -> 400 x 40 = **16000 particles**,
  density = Murnaghan reference `rho0 = 1` (so `P = 0` initially).
- Driver: homologous stretching `vx = 0.1 * x`, `vy = 0`. `div(v) = 0.1 > 0`
  everywhere -> the fluid expands, `rho` drops below `rho0`, and the Murnaghan
  EOS `P = K0/n ((rho/rho0)^n - 1)` goes **negative (tension)** everywhere.
- Generated by `generateIC_tensile.py` -> `tensile_ic.h5`.

## Physics flags (compile-time, in the source snapshot under `source/`)

| flag | value | reason |
|------|-------|--------|
| `EOS` | 1 (Murnaghan) | ideal gas cannot reach `P < 0`; Murnaghan does for `rho < rho0` |
| `ELASTIC` | 0 | pure fluid; isolates the pressure-driven tensile mode |
| `TENSILE_CORRECTION` | 0 | safeguard OFF, so the kernel is the only thing that can suppress clumping |
| `PERIODIC_BOUNDARIES` | 1 | box above |
| `GIZMO_ELASTIC_FLUX` | 0 | required: errors under `ELASTIC 0` |
| `EXPLICIT_VOL_INTEGRATION` | 0 | required: errors under `PERIODIC`/`!ELASTIC` |
| `KERNEL_FUNCTION` | **3** (`mlh_cubic`) / **6** (`mlh_wendland`) | the only difference between the two builds |

Murnaghan material: `K0=1, n=4, rho0=1, mu=0` (sound speed `c=1` at `rho0`).

The `source/` snapshot was taken with `KERNEL_FUNCTION 6`; `mlh_cubic` is the
same source with `KERNEL_FUNCTION 3`. Everything else is identical.

## Run (from this directory)

```
./mlh_cubic    -c config_cubic.info     # -> output_cubic/
./mlh_wendland -c config_wendland.info  # -> output_wendland/
```

`timeEnd = 3.0`, snapshot stride `0.1` (timeStep 0.01 x h5DumpInterval 10) -> 31 dumps.

## What to look for

Under sustained tension, the cubic-spline run should develop particle
**clumping / void formation** (the tensile instability) that grows with time,
while the Wendland C2 run stays comparatively smooth. Compare the density and
particle-position fields between `output_cubic/` and `output_wendland/`.
